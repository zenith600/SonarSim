================================================================================
UNDERWATER ACOUSTIC SIMULATOR - COORDINATE SYSTEM REFERENCE
================================================================================

OVERVIEW
--------
The simulator uses a 3D Cartesian coordinate system to represent the underwater
environment. All measurements are in METERS.


COORDINATE AXES
---------------
X-axis: Width (left-right direction)
Y-axis: Length (front-back direction)  
Z-axis: Depth (vertical direction, DOWNWARD is positive)

          Y (Length)
          ↑
          |
          |
          |________→ X (Width)
         /
        /
       ↓
      Z (Depth)


ORIGIN POINT
------------
The origin (0, 0, 0) is located at:
- Front-left corner of the water volume
- At the water surface level

Example: For a 100m × 200m × 50m pool:
- X ranges from 0 to 100 meters (width)
- Y ranges from 0 to 200 meters (length)
- Z ranges from 0 to 50 meters (depth)


Z-AXIS DEPTH CONVENTION
-----------------------
IMPORTANT: Z-axis points DOWNWARD (positive Z = deeper water)

Z = 0     → Water surface
Z = 25    → 25 meters below surface (mid-depth for 50m pool)
Z = 50    → Seabed (for 50m deep pool)

This follows oceanographic convention where depth increases downward.


POSITION EXAMPLES
-----------------
In a 100m (X) × 200m (Y) × 50m (Z) pool:

[5, 12.5, 1.5]
  X=5m     → 5 meters from left wall
  Y=12.5m  → 12.5 meters from front wall
  Z=1.5m   → 1.5 meters below surface

[50, 100, 25]
  X=50m    → Center of pool (width)
  Y=100m   → Center of pool (length)
  Z=25m    → Middle depth

[95, 180, 45]
  X=95m    → Near right wall (5m from edge)
  Y=180m   → Near back wall (20m from edge)
  Z=45m    → Near seabed (5m from bottom)


VISUALIZATION GRID
------------------
In the 3D visualization:
- Each grid square = 10 meters
- Grid lines help you estimate distances
- Grid is displayed on the seabed (bottom) plane

For 100m × 200m pool:
- X-axis: 10 grid squares (100m ÷ 10 = 10)
- Y-axis: 20 grid squares (200m ÷ 10 = 20)


OBJECT PLACEMENT
----------------
When placing objects, the position represents the CENTER of the object:

Example: Block at position [30, 50, 10] with size [4, 6, 3]
- Center at X=30, Y=50, Z=10
- Extends from X=28 to X=32 (30 ± 2)
- Extends from Y=47 to Y=53 (50 ± 3)
- Extends from Z=8.5 to Z=11.5 (10 ± 1.5)


DIRECTION VECTORS
-----------------
Direction vectors indicate ray propagation direction:

[1, 0, 0]   → Moving in +X direction (right)
[-1, 0, 0]  → Moving in -X direction (left)
[0, 1, 0]   → Moving in +Y direction (forward)
[0, -1, 0]  → Moving in -Y direction (backward)
[0, 0, 1]   → Moving in +Z direction (downward/deeper)
[0, 0, -1]  → Moving in -Z direction (upward/shallower)

[1, 1, 0]   → Moving diagonally (right + forward, horizontal)
[0, 1, -1]  → Moving forward and upward at 45°


TYPICAL EMITTER SETUP
---------------------
Emitter near starting blocks (shallow, front-left):
Position: [5, 12.5, 1.5]
Direction: [1, 0, 0] (pointing right/across pool)

This mimics a sonar device mounted near the pool edge, pointing across
the swimming lanes.


TYPICAL HYDROPHONE POSITIONS
-----------------------------
Hydrophones (receivers) are placed strategically:

Shallow positions (Z ≈ 2-5m):
  - Monitor surface-level activity
  - Detect direct paths from emitters

Mid-depth positions (Z ≈ 20-30m):
  - Capture reflected rays
  - Monitor mid-water column

Deep positions (Z ≈ 40-48m):
  - Near seabed
  - Detect bottom-reflected rays


DISTANCE CALCULATIONS
---------------------
Distance between two points uses Euclidean formula:

distance = √[(x₂-x₁)² + (y₂-y₁)² + (z₂-z₁)²]

Example: Distance from [0, 0, 0] to [30, 40, 50]:
distance = √[30² + 40² + 50²] = √[900 + 1600 + 2500] = √5000 ≈ 70.7 meters


RAY PROPAGATION
---------------
Rays travel in straight lines until they hit:
1. Pool boundaries (walls, surface, seabed) → Reflection
2. Objects (gates, blocks) → Reflection/absorption
3. Hydrophones → Detection and recording

Ray color coding in visualization:
- Cyan (light blue): Direct rays (no bounces)
- Magenta (purple): Reflected rays (1+ bounces)


COORDINATE TIPS
---------------
1. Always check pool dimensions before placing objects
2. Keep emitters and hydrophones within pool bounds
3. Z=0 is surface; avoid placing objects at exactly Z=0
4. Use grid squares (10m) as rough measurement guide
5. Center of pool = [width/2, length/2, depth/2]


REFERENCE POOL DIMENSIONS
-------------------------
Default Olympic-style pool:
- Width (X): 100 meters
- Length (Y): 200 meters  
- Depth (Z): 50 meters
- Volume: 1,000,000 cubic meters

Standard swimming pool (for comparison):
- Width: 25m
- Length: 50m
- Depth: 2-3m


COMMON MISTAKES
---------------
✗ Using negative coordinates (pool starts at origin)
✗ Placing objects outside pool bounds
✗ Confusing Z-axis (remember: positive = deeper)
✗ Forgetting object positions are CENTER points
✗ Mixing up width (X) and length (Y)

✓ Keep all coordinates positive
✓ Verify objects fit within pool dimensions
✓ Remember Z increases downward
✓ Account for object size when positioning
✓ X = width, Y = length, Z = depth
